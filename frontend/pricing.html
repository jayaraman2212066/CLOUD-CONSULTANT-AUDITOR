🗄️ What happens to your uploaded Prowler JSON?

Your JSON file is parsed in memory on the backend server and never written to disk. The only data retained is a scan summary (score, grade, severity counts — no finding details, no resource names, no ARNs) stored locally in scan_history/ keyed by an MD5 of your company name, used solely to render the score-trend chart on repeat scans. This summary is retained for up to 12 scans. No data is sent to any third-party analytics, logging, or cloud storage service.
